# Domino Notebooks

Domino (https://github.com/pritykinlab/domino) is a sequence-to-insulation deep learning framework. This repository contains notebooks and code used to generate the main and supplementary figures for the Domino paper. 

## Directory Structure

Notebooks for each main figure and associated supplementary figure(s) are in the following directories:

- Figure 1
    - `Fig1/Main_Figure1.ipynb`: plots and analysis for Figure 1.
    - `Fig1/Supp_Figure1_hyperparameter_sweep.ipynb`: plots and analysis for Figure S1A.
    - `Fig1/Supp_Figure1_window_region_performance.ipynb`: plots and analysis for Figure S1B.
    - `Fig1/Supp_Figure1_nhomie_validation.ipynb`: plots and analysis for Figure S1C,S1D.
- Figure 2
    - `Fig2/Main_Figure2A.ipynb`: plots and analysis for Figure 2A.
    - `Fig2/Main_Figure2B.ipynb`: plots and analysis for Figure 2B.
    - `Fig2/Main_Figure2C.ipynb`: plots and analysis for Figure 2C.
    - `Fig2/Main_Figure2DE.ipynb`: plots and analysis for Figure 2D,2E.
    - `Fig2/all_nc14_pattern_to_target_dict.json`: JSON file mapping pattern to target and source for embryonic motifs.
    - `Fig2/external_ppms.json`: JSON file mapping motif to external PPMs generated by `scripts/reference_pwms.ipynb` (see below for description).
- Figure 3
    - `Fig3/Main_Figure3A.ipynb`: plots and analysis for Figure 3A.
    - `Fig3/Main_Figure3CD.ipynb`: plots and analysis for Figure 3C,3D.
- Figure 4
    - `Fig4/Main_Figure4.ipynb`: plots and analysis for most of Figure 4 (except for the following notebook below) and Figure S4A-C.
    - `Fig4/Main_Figure4_M8_AAG3_ZF.ipynb`: plots and analysis for Figure 4A,4I (matching Domino motifs against 4ZF predictions).
    - `Fig4/Supp_Figure4_factor_expression.ipynb`: plots and analysis for Figure S4G (matching Domino motifs against 4ZF predictions).
- Figure 5
    - `Fig5/Main_Figure5.ipynb`: plots and analysis for most of Figure 5 (except for Figure 5F), Figure S5A,S5D-G,S5I.
    - `Fig5/Main_Figure5F.ipynb`: plots and analysis for Figure 5F.
    - `Fig5/Supp_Figure5_test_bound_stats.ipynb`: plots and analysis for Figure S5B,S5C.
    - `Fig5/Supp_Figure5_adjacent_boundaries.ipynb`: plots and analysis for Figure S5H.
- Figure 6
    - `Fig6/Main_Figure6.ipynb`: plots and analysis for Figure 6.
    - `Fig6/Supp_Figure6_synergy_map.ipynb`: plots and analysis for Figure S6.
    - `Fig6/nc14_motifs_for_synergy.csv`: motifs used for synergy analysis.
- Figure 7
    - `Fig7/Main_Figure7.ipynb`: plots and analysis for Figure 7.
    - `Fig7/Supp_Figure7_model_performance.ipynb`: plots and analysis for Figure S7A,S7B.
    - `Fig7/Supp_Figure7_track_correlations.ipynb`: plots and analysis for Figure S7C.
    - `Fig7/Supp_Figure7_larval_brain_clustermap.ipynb`: plots and analysis for Figure S8, S10A,S10C (larval brain).
    - `Fig7/Supp_Figure7_adult_brain_clustermap.ipynb`: plots and analysis for Figure S9, S10B,S10C (adult brain).
    - `Fig7/neg_pattern_to_target_dict_larval.json`: JSON file mapping pattern to target and source for larval brain motifs.
    - `Fig7/neg_pattern_to_target_dict_adult.json`: JSON file mapping pattern to target and source for adult brain motifs.

Scripts used for analysis are located in the `scripts` directory:

- `scripts/reference_pwms.ipynb`: notebook used for creating reference PWMs for motifs for visualization purposes. Motifs were either created manually to match a published sequence logo (this was for motifs without publicly available PWM representation) or directly obtained from zf.princeton.edu.
- `scripts/get_attributions.py`: script for obtaining attributions from select set of boundaries using trained model. Parameters are specified in a YAML file (see `nc14_config.yaml` for an example).
- `scripts/process_boundaries.py`: script flagging whether boundaries are in regions with undefined values (visually appearing as stripes).
- `scripts/run_motif_synergy.py`: script for obtaining motif synergy values.

## Data Availability

Data associated with this manuscript is provided as supplementary files. This includes 4-zinc-finger motif predictions and associated metadata, newly generated Micro-C data, and boundary atlases for the *Drosophila* embryo, larval, and adult brain.
